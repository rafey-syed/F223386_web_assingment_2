#  FreshMart - Grocery Store Web Application

Hey there! 
This is a simple grocery store web app I created as part of a project. I’ve tried to keep it clean, responsive, and easy to use — using only frontend tools like HTML, CSS, JavaScript, jQuery, JSON, Ajax and Bootstrap. It includes different pages like shop, login, signup, and even an admin dashboard!

---

## 📌 Features

-  Login & Signup pages (with validation)
-  Shop page with grocery products
-  Chatbot using jQuery, Ajax and JSON-based FAQs
-  Admin panel (Add, Update, Delete products - just UI, no backend)
-  Fully responsive using Bootstrap
-  Light modern UI with icons (Font Awesome)
-  Simple, clean structure for learning or extending

---

## 🧰 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla + jQuery + Ajax + Json)
- Bootstrap 5
- Font Awesome (for icons)
